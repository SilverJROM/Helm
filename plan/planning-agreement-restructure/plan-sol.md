Status: independent effort-planner output for `[north]` synthesis. Scope is exactly

## Execution invariants

- Phase order is a hard dependency gate: every P1 slice waits for all P0 leaves, every P2 slice waits
  for the P1 leaf, and every P3 slice waits for the P2 leaf.
- Agreement is engine state over `{attempt_id, round, plan_sha256, configured_seat_id}`. A model callback
  is evidence submitted to that state machine, never authority to declare agreement.
- There is no `transport.send`. Every review round spawns fresh reviewer transport seats for the frozen
  plan hash. A BROKEN round also gets an engine-dispatched revision-author turn; no transition depends on
  an ended CLI turn noticing a file change.
- Commit `8024452`'s convene-race protection is retained unchanged. The mandatory guard remains
  `grep -c planMdPathForRaceGuard src/services/planning-phase-service.ts == 3`.
- All automated tests are token-free: fake transports/callbacks, fake clocks, temporary databases, and
  filesystem fixtures only. Tests run file-by-file and never use `data/helm.db` or cycle 13.
- `HELM_SESSION_JANITOR` stays `0`; no slice enables it. No slice merges to `main`.
- `budget` is the coordinator envelope: `fix` implementation attempts, `rt` red-team iterations,
  `wall` minutes, `tok=null` no artificial token cap, and `ncs` new-class rounds before escalation.
